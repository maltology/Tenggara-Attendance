# Tenggara Attendance

Sistem pengurusan kehadiran staff untuk **Tenggara Sports**.

## Ciri-ciri

- ✅ **Dashboard Interaktif** — Ringkasan jumlah jam harian, mingguan & bulanan setiap staff dengan carta bar & line chart
- ✅ **Rekod Check In / Check Out** — Masukkan tarikh, masa masuk & keluar dengan pengiraan jam automatik
- ✅ **Senarai Rekod Kehadiran** — Jadual lengkap dengan carian, penapis staff & bulan
- ✅ **Pengurusan Staff** — Tambah, aktif/nyahaktif & padam staff
- ✅ **Data disimpan di browser** (localStorage) — tiada server diperlukan

## Cara Jalankan

```bash
npm install
npm run dev
```

Buka [http://localhost:3000](http://localhost:3000)

## Tech Stack

- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- Recharts
- date-fns

## Deploy

Boleh di-deploy terus ke Vercel dengan push ke repo ini.
